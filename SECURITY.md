# Security Policy

## Supported versions

Security fixes are provided in the latest stable release. Older releases
do not receive backported fixes. Please update before reporting an issue
that may already have been fixed.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub:

https://github.com/TheArqsz/JSRecon-Buddy/security/advisories/new

Do not open a public issue containing an unpatched vulnerability or
sensitive information.

Include:

- The extension version and browser version.
- A description of the issue and its potential impact.
- Minimal reproduction steps using synthetic data or a system you are
  authorized to test.

Do not include real credentials, personal data, or findings from
third-party systems without permission.

This project is maintained on a best-effort basis. No fixed response
or resolution time is guaranteed.

Use ordinary GitHub issues for non-security bugs and feature requests.
